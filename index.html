Cyan jacks are outputs, violet jacks are inputs. Patch from output → input (inputs stay dim until you drag from an output). On phones: tap an output, then tap an input — or drag a cable onto a knob (hits its primary inlet) or jack. Each cable has attenuverter dots near both ends; click for depth/polarity, double-click (or click the cable) to remove.

Osc B is independent of Osc A. Set Osc B→A Mode to Mix and use Amt / Xfade to crossfade A↔B in the main path; other modes (FM / AM / Ring / Fold / Sync) are modulation, not a blend. MIDI is 4-voice polyphonic on Osc A (shared Osc B + FX). While any MIDI note is held, Pitch and Osc B Pitch become ±semitone offsets (0 = unison); otherwise they are absolute Hz.

Commands (type into the field by the scope, or use the keyboard on desktop): 0-9 latch a preset (pad 0 is the default), ed3 arm/exit edit mode on preset 3, xy toggle the Lissajous scope, rd randomize, share copy a hashed URL of the current sound (also the SHARE button), xprt start/stop recording (16-bit wav, or 24-bit in hq), hq toggle high-quality audio, mic toggle microphone input, n3name name preset 3, psave/pload/pxprt/pimprt persist or export/import presets, fllp/flhp/flbp/flnt/floff set Filter2's mode, icons toggle icon/text labels.

Envelopes loop by default. TRIG fires one, LOOP turns looping off or on. SEQ outlets (Pitch / CV / Gate / Clock) stay visible at the top — patch Seq Pitch to Pitch, Fold, Osc B, or Filter as you like. A status line under SEQ shows playhead and pattern. Default seq mode is pitch. A second row of LFO / Env / Random outs sits above the delay section. Delay Stereo Width keeps L/R through Absorb (0=mono, 1=wide); FB Freq Shift Bode-shifts the feedback loop (±Hz). sq status, sqplay/sqstop, sqmode pitch|trig, bpm120, sq n c4 e4 . g4 notes, sq d 8 8 4 durations, sq p 0 0 3 presets (values only), sq e 5 8 Euclidean, sqdiv16 sqlen16 sqclear sqshow. Saved with presets.

MIC arms a low-latency external input (echo cancel / AGC off). Patch the Mic out jack anywhere, or feed Ext In to run the mic through the filter / fold / delay / FX path.

Serve this folder over HTTP (e.g. python3 -m http.server) so AudioWorklets can load from omchs-worklets.js. Mic also needs HTTPS or localhost.
