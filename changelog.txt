Omchs changelog
===============

2026-09-19
- Factory presets now load from omchs-presets-defaults.json and are assigned
  to the numbered pad buttons (1-9, then 0).
- If a preset bank exists in localStorage (key omchs-presets-v1), that bank
  overrides the JSON factory set after it loads. Use psave after editing to
  keep the override; a fresh browser with no saved bank uses the JSON file.
- Shared applyPresetBank() so factory load, localStorage restore, and pimprt
  all fill the same 10 slots and refresh pad titles.
- If the JSON file cannot be fetched (not served over HTTP, missing file),
  pads start empty and a terminal message is logged.
- Added commands.txt listing typed commands and keyboard shortcuts.
- High-quality audio mode, toggled with hq (no UI switch). Off = interactive
  latency, cheap fold, WaveShaper 2x, 16-bit wav. On = playback latency,
  96kHz if the browser allows it, 4x oversampled fold, WaveShaper 4x,
  24-bit wav, scope glow off. Remembered in localStorage (omchs-hq). If the
  engine is already running, hq rebuilds the graph and keeps the patch.
- Terminal prints the current sample rate / latency / oversampling / wav
  depth on page load, after power-on, and after hq.
- Sequencer V1 (terminal): internal clock, pitch or trig mode, per-step
  duration, rests, Euclidean fill, values-only preset-per-step, one-shot
  envelopes. Pattern is stored with the preset bank (psave / pxprt / sqsave).
- Knob, jack, and cluster labels default to text instead of icons. icons
  still toggles back to symbols. Keyboard command buffer now accepts spaces
  and # so sequencer note strings can be typed.
- Sequencer stays stopped on power-on. Envelopes loop by default; TRIG fires
  a cycle on demand and LOOP toggles looping per envelope.
- Sequencer has its own SEQ faceplate (Seq Pitch / Seq CV / Seq Gate /
  Seq Clock outlets). Pitch is no longer hard-wired to Osc A — patch Seq
  Pitch to Pitch, Fold, Osc B, or Filter as needed.
- Env1 sits next to LFO1 and Env2 next to LFO2 so the row wraps as pairs
  on a phone. Preset pads 0–9 latch like a typical synth; pad 0 is the
  default, with an LED on each plate.
